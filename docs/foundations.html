基础语言总览

这一组就是前端最基础的那层能力：页面怎么写、逻辑怎么组织、类型怎么看、代码怎么协作。

建议从这里开始​

  1. HTML / CSS：先建立页面结构和布局能力
  2. JavaScript：补齐运行时、语法、常用方法和思维模型
  3. TypeScript：把类型系统接到真实项目里
  4. Git：保证协作和提交习惯稳定
  5. 数据结构与算法：不用一口气学完，先建立结构感就够了

这一组都放了什么​

  • HTML：语义化、脚本加载、表单、媒体标签、现代离线能力
  • CSS：布局、选择器、动画、工程化、预处理器、CSS Modules、PostCSS 与常见面试点
  • JavaScript：语言基础、数组/字符串、工具方法、浏览器 API
  • TypeScript：基础类型、泛型、高级类型，以及项目接入、案例与配置
  • 工程化：构建、规范、请求层、监控，以及运行时边界怎么收住
  • Git：常用命令、PR 流程、tag、rebase
  • 数据结构与算法：前端常见题型对应的数据结构基础
