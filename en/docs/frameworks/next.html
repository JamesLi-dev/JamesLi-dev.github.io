  • Next.js 14、15、16 更新对比

这组内容主要在解决什么​

  • 从 9.0 看到 16，Next.js 的重心到底怎么变了
  • 现在一套 Next 项目，目录、路由、渲染、缓存和写操作分别该怎么理解
  • Pages Router 为什么慢慢退到存量维护位置
  • App Router、缓存、Turbopack、Server Components 是怎么接成一条主线的
  • 从老项目升级到新版本，真正要先检查什么

一句话总结​

如果把这几年压成一句话，Next.js 的路线大致是：

  • 9 / 10：把 React SSR 框架的基础能力做扎实
  • 11 / 12：开始明显强化性能和编译链
  • 13 / 14：App Router 和 React Server Components 成为主轴
  • 15 / 16：缓存语义、请求时 API、Turbopack、代理边界继续收口，整个框架越来越像一套完整的全栈运行模型
