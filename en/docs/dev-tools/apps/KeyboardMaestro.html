Keyboard Maestro

Keyboard Maestro​

Keyboard Maestro（以下简称 KM）能做的事情，其实大都能通过系统本身加上 Automator、AppleScript、ShellScript 等方式完成，只是脚本门槛会高不少。 它把很多自动化动作做成了可视化编排和可视化管理，省掉了不少零散脚本和快捷键维护成本。这也是把它放进工具清单的主要原因。

我的使用：​

这里主要把 Keyboard Maestro 当做一款快捷键管理软件来用，可以在软件里自定义快捷键，再去控制软件的隐藏显示。

教程其实很简单​

Other​

除此之外它的功能可自定程度很高，例如：

  • 快捷键浏览器搜索
  • 执行工作流，例如：我先 复制文本 -> 打开应用窗口 -> 然后粘贴文本
  • 清空回收站
  • 组合快捷键
