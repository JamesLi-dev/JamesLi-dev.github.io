项目背景​

一个基于 BSC (Binance Smart Chain) 的 DeFi 项目前端应用，主要功能包括代币发行平台（Launchpad）、NFT 孵化器、代币交易（Swap）和项目展示空间。项目采用现代化 Web3 技术栈，集成了多个区块链服务和 API。

  • React 18.2 + TypeScript 5.8
  • Vite 6.2 - 构建工具
  • React Router 6 - 路由管理
  • TailwindCSS 4.0 - 样式框架
  • Zustand 4.4 - 轻量级状态管理

为什么有两个版本​

项目最初基于 PancakeSwap V2 开发，但在后续迭代中，为了满足客户对自定义费率（Custom Fee Tiers）的特定需求，我们需要引入 V3 的集中流动性机制。此外，V2 版本早期依赖的第三方索引服务出现了不可预期的稳定性问题。为了确保系统的长期稳定性和功能的灵活性，我们决定全面集成 PancakeSwap V3，同时保留 V2 以兼容旧有的流动性池，从而形成了当前双版本并存的架构。

V2 工作原理：

PancakeSwap V2 基于 Uniswap V2 的恒定乘积做市商（AMM）模型：

  • 公式：x * y = k（其中 x 和 y 是池中两种代币的数量，k 是常数）
  • 价格计算：价格由两种代币的储备量比例决定
  • 流动性：流动性均匀分布在整个价格曲线上（0 到 ∞）
  • 手续费：固定 0.25%（其中 0.17% 给 LP，0.08% 用于回购销毁）

详细实现：

1. 代币兑换估算 (useSwapEstimate)

Trade 对象提供的关键信息：

  • executionPrice: 执行价格（考虑滑点和手续费）
  • nextMidPrice: 交易后的中间价格
  • priceImpact: 价格影响百分比
  • outputAmount: 预期输出金额
  • minimumAmountOut(slippage): 考虑滑点后的最小输出

2. 执行兑换 (useSwap)

// src/hooks/swap.ts - 完整交易流程
export function useSwap() {
  return useMutation({
    mutationFn: async ({
      inputToken,
      outputToken,
      amount,
      slippagePercent = 0.5,
    }) => {
      const amountIn = BigInt(
        parseUnits(amount, inputToken.decimals).toString()
      );

      // ========== 步骤1: 检查并授权 ==========
      const allowance = await getAllowance(
        inputToken.address,
        userAddress,
        BSC_ROUTER_ADDRESS,
        publicClient
      );

      if (allowance < amountIn) {
        const erc20 = getContract({
          address: inputToken.address,
          abi: erc20Abi,
          client: walletClient,
        });

        // 授权 100 倍金额，减少后续交易的授权次数
        await erc20.write.approve([BSC_ROUTER_ADDRESS, amountIn * 100n]);
      }

      // ========== 步骤2: 计算交易参数 ==========
      const pair = await Fetcher.fetchPairData(
        inputToken,
        outputToken,
        walletClient
      );
      const route = new Route([pair], inputToken, outputToken);
      const trade = new Trade(
        route,
        CurrencyAmount.fromRawAmount(inputToken, amountIn.toString()),
        TradeType.EXACT_INPUT
      );

      // 交易路径（支持多跳，如 A -> B -> C）
      const path = [inputToken.address, outputToken.address];

      // 交易截止时间（20分钟后）
      const deadline = Math.floor(Date.now() / 1000) + 60 * 20;

      // 滑点计算：0.5% = 50 / 10000
      const slippage = new Percent(
        Math.floor(slippagePercent * 100).toString(),
        "10000"
      );

      // 最小输出金额（滑点保护）
      const amountOutMin = BigInt(
        trade.minimumAmountOut(slippage).quotient.toString()
      );

      // ========== 步骤3: 调用 Router 合约 ==========
      const router = getContract({
        address: BSC_ROUTER_ADDRESS,
        abi: routerAbi,
        client: walletClient,
      });

      const tx = await router.write.swapExactTokensForTokens([
        BigInt(amountIn), // 精确输入金额
        BigInt(amountOutMin), // 最小输出金额（滑点保护）
        path, // 交易路径
        address, // 接收地址
        BigInt(deadline), // 截止时间
      ]);

      return { tx };
    },
  });
}

Router 合约主要方法：

  • swapExactTokensForTokens: 精确输入金额交易
  • swapTokensForExactTokens: 精确输出金额交易
  • swapExactETHForTokens: BNB 换代币
  • swapExactTokensForETH: 代币换 BNB

V3 工作原理：

PancakeSwap V3 基于 Uniswap V3 的集中流动性模型：

  • 集中流动性：LP 可以在特定价格区间内提供流动性，提高资金效率
  • 多费率档位：支持 0.01%, 0.05%, 0.25%, 1% 四个费率档位
  • 价格表示：使用 sqrtPriceX96 格式（Q64.96 定点数）
  • Tick 系统：价格空间被划分为离散的 tick，每个 tick 代表 0.01% 的价格变化
  • 非同质化 LP：每个 LP 位置是独特的 NFT

项目使用的费率档位：

// src/hooks/swap_v3.ts
export const V3_FEE_TIERS = [2500, 10000] as const;
// 2500 = 0.25% (适合大多数代币对)
// 10000 = 1% (适合波动性较大的代币对)

// 完整的费率档位（PancakeSwap V3 支持）：
// 100 = 0.01% (稳定币对，如 USDT/USDC)
// 500 = 0.05% (相关资产，如 ETH/WBTC)
// 2500 = 0.25% (标准代币对)
// 10000 = 1% (异常代币对)

详细实现：

1. 查询流动性池

// src/hooks/swap_v3.ts

// 查询所有费率档位的池子
export async function getV3PoolsForPair(
  publicClient: PublicClient,
  tokenA: Address,
  tokenB: Address
): Promise<V3PoolInfo[]> {
  const factory = getContract({
    address: BSC_SWAP_V3_FACTORY_ADDRESS,
    abi: v3FactoryAbi,
    client: publicClient,
  });

  const results = await Promise.all(
    V3_FEE_TIERS.map(async (fee) => {
      // 调用 Factory.getPool 获取池子地址
      const pool = await factory.read.getPool([tokenA, tokenB, fee]);

      // 如果池子不存在，返回 null
      if (pool === "0x0000000000000000000000000000000000000000") return null;

      // 读取池子的流动性
      const poolReader = getContract({
        address: pool,
        abi: v3PoolLiquidityAbi,
        client: publicClient,
      });
      const liquidity = await poolReader.read.liquidity();

      return { fee, poolAddress: pool, liquidity };
    })
  );

  // 过滤掉不存在的池子
  return results.filter((x): x is V3PoolInfo => x !== null);
}

// 自动选择流动性最大的池子
export async function getBestV3PoolForPair(
  publicClient: PublicClient,
  tokenA: Address,
  tokenB: Address
): Promise<V3PoolInfo | null> {
  const pools = await getV3PoolsForPair(publicClient, tokenA, tokenB);
  if (pools.length === 0) return null;

  // 返回流动性最大的池子
  return pools.reduce((best, cur) =>
    cur.liquidity > best.liquidity ? cur : best
  );
}

路径编码函数（V3 特有）：

// src/hooks/swap_v3.ts

// V3 路径编码：代币地址 + 费率 + 代币地址 + ...
function encodePath(tokens: Address[], fees: number[]): `0x${string}` {
  if (tokens.length !== fees.length + 1) {
    throw new Error("路径编码错误：代币数量应该比费率数量多1");
  }

  let encoded = "0x";
  for (let i = 0; i < fees.length; i++) {
    // 添加代币地址（去掉 0x 前缀，40 个字符）
    encoded += tokens[i].slice(2);

    // 添加费率（3 字节 = 6 个十六进制字符）
    encoded += fees[i].toString(16).padStart(6, "0");
  }
  // 添加最后一个代币地址
  encoded += tokens[tokens.length - 1].slice(2);

  return encoded as `0x${string}`;
}

// 示例：
// encodePath(['0xAAA...', '0xBBB...'], [2500])
// 结果：'0xAAA...0009c4BBB...'
//       (AAA 地址 + 0x0009c4(2500) + BBB 地址)

// 多跳示例：
// encodePath(['0xAAA...', '0xBBB...', '0xCCC...'], [2500, 10000])
// 结果：'0xAAA...0009c4BBB...002710CCC...'

export function useSwapV3() {
  return useMutation({
    mutationFn: async ({
      inputToken,
      outputToken,
      amount,
      slippagePercent = 0.5,
    }) => {
      const amountIn = BigInt(
        parseUnits(amount, inputToken.decimals).toString()
      );

      // ========== 步骤1: 找到最佳池子 ==========
      const poolInfo = await getBestV3PoolForPair(
        publicClient,
        inputToken.address,
        outputToken.address
      );

      if (!poolInfo) throw new Error("No pool found");

      // ========== 步骤2: 检查并授权 ==========
      const allowance = await getAllowance(
        inputToken.address,
        userAddress,
        BSC_SWAP_V3_ROUTER_ADDRESS,
        publicClient
      );

      if (allowance < amountIn) {
        const erc20 = getContract({
          address: inputToken.address,
          abi: erc20Abi,
          client: walletClient,
        });

        // 授权 100 倍金额
        await erc20.write.approve([
          BSC_SWAP_V3_ROUTER_ADDRESS,
          amountIn * 100n,
        ]);
      }

      // ========== 步骤3: 使用 Quoter 计算预期输出 ==========
      const quoter = getContract({
        address: BSC_V3_QUOTER_ADDRESS,
        abi: quoterAbi,
        client: publicClient,
      });

      // 检查池子流动性（V3 特有）
      const poolData = await getPoolData(poolInfo.poolAddress, publicClient);
      if (poolData.liquidity === 0n) {
        throw new Error("池子没有流动性，无法进行交易");
      }

      const path = encodePath(
        [inputToken.address, outputToken.address],
        [poolInfo.fee]
      );

      const { result } = await quoter.simulate.quoteExactInput([
        path,
        amountIn,
      ]);
      const expectedAmountOut = result[0];

      // ========== 步骤4: 计算滑点保护 ==========
      // V3 需要更严格的滑点保护，因为流动性是集中的
      const slippageBN = new BigNumber(slippagePercent).div(100);
      const safeSlippage = slippageBN.plus(0.01); // 额外增加 1% 安全边距

      const amountOutMin = BigInt(
        new BigNumber(expectedAmountOut.toString())
          .times(new BigNumber(1).minus(safeSlippage))
          .toFixed(0)
      );

      const deadline = BigInt(Math.floor(Date.now() / 1000) + 60 * 20);

      // ========== 步骤5: 调用 Router.exactInputSingle ==========
      const router = getContract({
        address: BSC_SWAP_V3_ROUTER_ADDRESS,
        abi: swapRouterAbi,
        client: walletClient,
      });

      const params = {
        tokenIn: inputToken.address,
        tokenOut: outputToken.address,
        fee: poolInfo.fee, // uint24 费率
        recipient: address,
        deadline,
        amountIn,
        amountOutMinimum: amountOutMin,
        sqrtPriceLimitX96: 0n, // 0 表示不设置价格限制
      };

      const tx = await router.write.exactInputSingle([params]);

      return { tx };
    },
  });
}

Router 合约主要方法：

  • exactInputSingle: 单跳精确输入交易
  • exactInput: 多跳精确输入交易
  • exactOutputSingle: 单跳精确输出交易
  • exactOutput: 多跳精确输出交易

export function useTokenPriceV3(
  tokenAddress: Address,
  baseTokenAddress?: Address
) {
  const publicClient = usePublicClient();

    },
